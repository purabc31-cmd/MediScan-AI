ABOUT THE PROJECT

Useful research.
Honest boundaries.

MediScan AI is a modular medical imaging research prototype. The current Python service includes a 2D MRI classification workflow, optional binary segmentation, Grad-CAM visualisation and PDF research output. It does not currently provide CT or X-ray inference, complete 3D study analysis or clinically validated findings.
